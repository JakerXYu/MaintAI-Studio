# Demo data

This directory holds the deterministic synthetic dataset used by the P0 demo
scripts and end-to-end tests.

## What is here

- `synthetic/maintai_ai4i_style_demo.csv` — the committed default CSV produced
  by `scripts/generate_demo_data.py`.

## Provenance

The CSV is **synthetic**, generated by a fixed-seed (42) Python script. It is
*inspired by the schema shape* of the public
[AI4I 2020 Predictive Maintenance dataset](https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset)
(UCI Machine Learning Repository, S. Matzka, "Explainable Artificial
Intelligence for Predictive Maintenance Applications", 2020): a compact
10-column telemetry analogue (`timestamp`, `machine_id`, `serial_no`, `type`,
`air_temperature`, `process_temperature`, `rotational_speed`, `torque`,
`tool_wear`, `machine_failure`) and the L/M/H product-type vocabulary.

It is **not** a copy of the UCI original. Every value is synthesised here, and
no UCI row is reproduced. A small amount of missing data, a flatline sensor, a
torque outlier, and one duplicate row are injected deterministically so the
demo exercises the data-quality path.

## Privacy

The data contains no personal information, no real asset identifiers, and no
production telemetry. All values are synthetic.

## Licence

The synthetic data is generated by this repository and contains no copied
third-party rows. Its distribution terms follow the repository license once
one is selected. The AI4I dataset is referenced only for schema inspiration;
its own UCI license terms apply to the original, not this synthetic file.

## Regeneration

The file is byte-for-byte reproducible (fixed seed, no randomness beyond the
seeded generator):

```bash
python scripts/generate_demo_data.py
```
