# Benchmarks

This document indexes the two benchmark tracks in this repository and freezes
their facts. The two tracks serve different purposes and must not be conflated:

- **AI4I / Internal Demo Track** — deterministic synthetic data that exercises
  the full product workflow. It is a *workflow/demo* track, not external proof.
- **Scania APS External Benchmark** — real public industrial data used to
  validate the profiling / task / train / evaluate / recommend core against a
  fixed external holdout.

---

## AI4I / Internal Demo Track

- **Data**: `data/synthetic/maintai_ai4i_style_demo.csv`, generated by
  `scripts/generate_demo_data.py`.
- **Nature**: synthetic. Every row is synthesized in-repo; no UCI row is copied.
  The schema *shape* is inspired by the public
  [AI4I 2020 Predictive Maintenance dataset](https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset)
  (UCI, S. Matzka, "Explainable Artificial Intelligence for Predictive
  Maintenance Applications", 2020): a 10-column telemetry analogue
  (`timestamp`, `machine_id`, `serial_no`, `type`, `air_temperature`,
  `process_temperature`, `rotational_speed`, `torque`, `tool_wear`,
  `machine_failure`) with L/M/H product types.
- **Determinism**: fixed seed `42`; the CSV is byte-for-byte reproducible and a
  small amount of missing data, a flatline sensor, a torque outlier, and one
  duplicate row are injected deterministically to exercise the data-quality
  path.
- **Purpose**: drives the P0/P1 workflow demo and end-to-end tests
  (ingest → profile → task → train → explain → register → predict → UI →
  audit). It is the default demo dataset and contains no personal data, no real
  asset identifiers, and no production telemetry.
- **Status**: it is **not** an external benchmark and **not** primary external
  proof of model quality. It demonstrates the loop works end-to-end and
  deterministically. Provenance, privacy, and license notes:
  [`data/README.md`](../data/README.md).

## Scania APS External Benchmark

This track runs the public UCI **APS Failure at Scania Trucks** dataset through
the fixed MaintAI model catalog and freezes the result. It is real external
industrial data, not an ABB dataset and not part of the synthetic demo.

### Dataset

- Name: **APS Failure at Scania Trucks** (air pressure system failure in
  heavy trucks).
- Source: UCI Machine Learning Repository, DOI `10.24432/C51S51`.
- Creator: **Scania CV AB**; data originates from real operational heavy-truck
  APS systems.
- Page: <https://archive.ics.uci.edu/dataset/421/aps+failure+at+scania+trucks>.
- Feature count discrepancy (frozen): the UCI page says **171** features, but
  the actual downloaded archive contains **171 columns total = `class` + 170
  anonymous features**. The benchmark uses the archive as the executable fact
  and records the discrepancy; **no fabricated 171st feature is added**, and no
  business meaning is guessed for the anonymous feature names.
- License: UCI listing is CC BY 4.0; the archive's bundled description also
  carries a GPL-3.0-or-later notice from Scania CV AB. Both notices are recorded
  without reinterpretation.

### Official split (frozen)

| Split | Rows | Negative (`neg`) | Positive (`pos`) | Missing-cell rate |
|---:|---:|---:|---:|---:|
| Train | 60,000 | 59,000 | 1,000 | 8.2847% |
| Test  | 16,000 | 15,625 | 375 | 8.3582% |

- The **official** train/test holdout is preserved exactly; no random split is
  performed, and the test set is never mixed into any fitted transformer.
- Missing cells (frozen): train `850,015 / 10,260,000` cells (8.2847%), test
  `228,680 / 2,736,000` cells (8.3582%). The `na` token is converted to `NaN`
  before MaintAI preprocessing.

### Preprocessing

- Reuses the existing P0 pipeline: numeric median imputation; the Logistic
  Regression numeric path is additionally standard-scaled.
- **All transformers fit on the official train split only.** No business feature
  engineering is derived from the anonymous column names.

### Models and protocol

- Models: **Logistic Regression**, **Random Forest**, **XGBoost**, run through
  the fixed MaintAI model catalog (`binary_classification` task).
- Seed: `42`.
- Decision threshold: `0.5` for all three models. **No threshold optimization**
  and no hyperparameter or threshold tuning on the test set.
- Primary-metric field named **PR-AUC** is implemented as scikit-learn
  `average_precision_score` (Average Precision), because the positive class is
  extremely rare.
- The official test set is consumed by the **three-model post-hoc ranking**
  (`recommend()` / `compare_costs()`). It is therefore a benchmark winner, not a
  still-unbiased holdout for future tuning.

### Results (frozen, 2026-09-01)

| Model | Precision | Recall | F1 | PR-AUC (AP) | ROC-AUC | FP | FN | Total Cost |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| Logistic Regression | 0.837580 | 0.701333 | 0.763425 | 0.816266 | 0.976923 | 51 | 112 | 56,510 |
| Random Forest        | 0.946281 | 0.610667 | 0.742301 | 0.897315 | 0.995625 | 13 | 146 | 73,130 |
| XGBoost              | 0.945578 | 0.741333 | 0.831091 | 0.927419 | 0.996165 | 16 | 97  | **48,660** |

Confusion matrices (TN / FP / FN / TP):

- Logistic Regression: 15,574 / 51 / 112 / 263
- Random Forest: 15,612 / 13 / 146 / 229
- XGBoost: 15,609 / 16 / 97 / 278

### Cost function

```
Total Cost = 10 * FP + 500 * FN
```

The `10` / `500` are the **IDA 2016 challenge cost units**, not MaintAI or ABB
real maintenance economics. Cost is computed by the independent
`maintai.ml.cost.compare_costs`.

### Interpretation

- **XGBoost** is best on PR-AUC, F1, and total cost (`48,660`).
- **Random Forest** has the fewest false positives (`13`) and the highest
  precision (`0.946281`), but its `146` false negatives drive cost to `73,130`.
- The industrial choice is **not** accuracy or precision alone: a missed faulty
  truck (FN) costs `500` versus `10` for an unnecessary check (FP), so low-FN
  models win on cost even when their precision is slightly lower.
- These are the fixed catalog / default hyperparameters on this holdout, not a
  fair leaderboard comparison against IDA submissions.

## Methodological Caveat

The official Scania APS test split has **already been consumed** by the
three-model post-hoc comparison and winner selection described above. It must
not be treated as an untouched holdout for any later work:

- Do **not** tune thresholds, hyperparameters, feature selection, or model
  choices after seeing the results on this page and then claim the same test is
  still an unbiased holdout.
- No threshold optimization was performed; these are fixed-catalog baselines,
  not cost-optimized solutions.
- Any future change that re-evaluates on this split must be labelled as a new,
  separate evaluation (post-hoc / post-improvement), never as a first look at a
  clean test set.
